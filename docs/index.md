# Spot documentation

Spot is a 2D/3D game engine for Windows, macOS and Linux. The documentation has two parts:

- **[The manual](manual/index.md)**, for making games with Spot: getting started, guides by task, and the
  reference for scripting and the command line.
- **[Internals](internals/index.md)**, for working on Spot itself: how each system works, why it is built that
  way, and where its code starts.

The [examples](../examples/) are small complete programs and projects, each built and run by the tests.
